# 🏦 Loan Management System

## 📌 About the Project
The Loan Management System is a Java-based application designed to
manage different types of loan applications. It helps users explore
loan options and evaluate eligibility based on validation rules.

This project demonstrates Object-Oriented Programming (OOP)
concepts using Java.

## 🚀 Features
- Multiple loan types:
  - Personal Loan
  - Home Loan
  - Gold Loan
  - Education Loan
  - Vehicle Loan
  - Business Loan
- Loan eligibility evaluation
- CIBIL score validation
- Customer information validation
- Phone number validation
- Aadhaar number validation
- PAN card format validation
- Menu-driven console interface

## 🛠️ Technologies Used
- Java
- Core Java
- Object-Oriented Programming (OOP)
- Eclipse IDE

## 🧠 OOP Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism
- Method Overriding
- Encapsulation

## 🎯 Project Objective
To develop a simple loan management application
while strengthening Java programming and OOP concepts.
